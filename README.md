**Walmart Sales Analysis – Business Analysis using Power BI**

This project focuses on analyzing Walmart's weekly sales data across 45 stores using Microsoft Power BI. It includes data loading, data cleaning, data validation, data modeling, DAX measures, chart creation, and interactive dashboard development.The dashboard provides insights into store-wise sales performance, average weekly sales, transaction counts, holiday impact, fuel price, and yearly sales trends.

**Key Features:**

* Data Loading and Cleaning
* Data Validation and Data Modeling
* DAX Measures (Total Weekly Sales, Average Weekly Sales, Total Transaction Count)
* Chart Creation (Column, Line, Donut, Area, Ribbon, Pie and Bar Charts)
* Interactive Power BI Dashboard with Year Slicer
* Store Performance Analysis
* Business Insights and Recommendations

**Key Insights:**

* Store 20 has the highest total weekly sales, while Store 33 has the lowest
* Total weekly sales across all 45 stores are about 6.74 billion
* Average weekly sales per store are about 1.05 million

**Tools Used:** Microsoft Power BI, Power Query, DAX

**Objective:** To transform raw sales data into meaningful insights and provide data-driven recommendations to improve the performance of low-selling stores and support better business decisions.
